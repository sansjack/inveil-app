# Getting help

Inveil is an open-source project maintained by volunteers. There is no guaranteed response time.

| I want to | Go to |
|---|---|
| Learn how it works or set it up | The [README](README.md) and [`docs/`](docs). [SELF_HOSTING.md](docs/SELF_HOSTING.md) and [CONFIGURATION.md](docs/CONFIGURATION.md) answer most setup questions. |
| Ask a question | GitHub Discussions if it is enabled for the repository, otherwise open an issue with the `question` label. Search existing issues first. |
| Report a bug | Open an issue with the bug report form. Include your version (`inveil --version`), operating system and architecture, your configuration with secrets removed, and what you expected. Use synthetic data only. |
| Request a feature | Open an issue with the feature request form and describe the problem you want solved. |
| Report a security problem | Do not open an issue. Follow [SECURITY.md](SECURITY.md). |
| Contribute | [CONTRIBUTING.md](CONTRIBUTING.md). |

Never post real personal data, API keys, tokens, private signing keys or full request bodies in a public place. Redact logs before sharing them.

This project does not provide support for third-party backends or for a hosted service.
